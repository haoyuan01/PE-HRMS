# Patch Notes

One file per release, named by version: `vMAJOR.MINOR.md` (e.g. `v1.1.md`).
Each note records its date and commit inside. Newest first below.

- `patch-notes/vX.Y.md` — **internal** notes: cause, files, endpoints, commits.
- `patch-notes/client/vX.Y.md` — **client-facing** notes: plain language, no
  technical details, safe to send to the client.
